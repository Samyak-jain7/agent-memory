# Locally served design fonts

Newsreader (upright/italic variable) and IBM Plex Mono (regular/medium) implement the original visual direction in `memory-system.html`. They are served from this application, with no third-party font requests.

Source: Google Fonts repository, retrieved 2026-10-04:
- https://github.com/google/fonts/tree/main/ofl/newsreader
- https://github.com/google/fonts/tree/main/ofl/ibmplexmono

Both families use the SIL Open Font License 1.1; original notices are retained in the adjacent `*-OFL.txt` files. Font files are unmodified.
